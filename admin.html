Instructions for Teachers

CRITICAL FORMATTING: Row 1 of your Excel file must have Student ID, Full name, Called name, and subject columns formatted exactly as SubjectName_Score, SubjectName_Behaviour, and SubjectName_Comment (e.g., Maths_Score, Maths_Behaviour) so that the app reads the information properly.
  1. Open your finalized class grades sheet in Microsoft Excel.
  2. Go to File > Save As.
  3. Change the file type to CSV (Comma delimited) (*.csv) and save it to your computer.
  4. Click the gold "Load Master CSV" button below and select the file you just saved.
  5. The system will automatically generate the tables and radar charts for every student!
  6. Review the individual reports using the dropdown menu at the top.
  7. When ready, click "Print" (ensure your printer is set to Landscape) OR click "Save as Doc" to download all reports into a single Microsoft Word document!
Note: If you upload the wrong file or need to refresh the data, simply click the red Reset button at the top to start over.
